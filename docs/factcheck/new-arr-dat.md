## 출처를 찾지 못해 빼거나 바꾼 주제
- 입항 절차의 고정 순서(입항 보고 → 도선사 승선 → 묘박 → 접안): 이 순서를 그대로 확인해 주는 출처를 찾지 못했다. 도선사 승선을 묘박 앞에 두는지 뒤에 두는지는 항만마다 다르다. 순서 문항은 만들지 않고, 국내 논문의 4단계(입항 → 양묘 → 접안 → 출항)와 대기시간 정의로 계산 문항(arr-mc-04)을 만들었다.
- SOF는 현지 시각(LT), AIS는 UTC라는 대비: SOF의 시간대 기재 관행을 뒷받침할 출처를 찾지 못했다. 그래서 AIS ETA가 UTC라는 사실만 써서 UTC → KST 환산 문항(dat-mc-04)을 만들었다.
- ATB·POB 약어: 항만당국·표준 문서의 공식 정의를 찾지 못했다. ATB는 문두에서 정의만 하고 구간 개념을 물었고(arr-mc-02), POB는 위키백과(보조 출처)로만 확인했다(arr-sa-02).
- 주간 접안 제한·기상 한계의 구체 수치, 울산항·SK 부두 고유의 운영 제약: 지시대로 출제하지 않았다.
- AIS 보고 간격(묘박·계류 3노트 이하 3분 등, ITU-R M.1371-6 A2-4.3.1.3·IMO A.1106 Table 2): 출처는 확인했지만, 15문항 안에서 'not available' 기본값 문항을 우선해 이번에는 넣지 않았다.
